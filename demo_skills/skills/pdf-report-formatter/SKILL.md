# PDF Report Formatter

## When to use

Use this skill when the user needs to format, standardize, or clean up technical PDF reports.

## Workflow

1. Inspect the input document.
2. Identify the report type.
3. Apply the company layout rules.
4. Validate headings, tables, captions, and page structure.
5. Return the cleaned report or a list of required changes.

## Inputs

- PDF reports
- Markdown drafts
- Engineering inspection notes

## Outputs

- Formatted report
- Change summary
- Validation notes

## Constraints

Do not modify technical meaning.
Do not invent measurements, serial numbers, equipment IDs, or inspection results.
